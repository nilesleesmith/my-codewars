# Greed is Good

**Rank:** 5 kyu  
**Language:** JavaScript

## Instructions

Score a roll of five dice in the Greed dice game. Three ones score 1000 points; three of any other face score that face times 100. Remaining ones score 100 each and remaining fives score 50 each. Other single dice score zero.

## Examples

- `score([2, 3, 4, 6, 2])` returns `0`.
- `score([1, 1, 1, 5, 1])` returns `1150`.
