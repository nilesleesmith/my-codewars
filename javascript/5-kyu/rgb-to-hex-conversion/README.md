# RGB To Hex Conversion

**Rank:** 5 kyu  
**Language:** JavaScript

## Instructions

Convert red, green, and blue component values into a six-character hexadecimal color value. Values below 0 are treated as 0 and values above 255 as 255. The result uses uppercase hexadecimal digits.

## Examples

- `rgb(255, 255, 255)` returns `"FFFFFF"`.
- `rgb(255, 255, 300)` returns `"FFFFFF"`.
