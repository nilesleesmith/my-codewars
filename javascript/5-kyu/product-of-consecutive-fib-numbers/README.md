# Product of consecutive Fib numbers

**Rank:** 5 kyu  
**Language:** JavaScript

## Instructions

Given a product, find two consecutive Fibonacci numbers whose product reaches or exceeds it. Return both numbers and a boolean indicating whether their product equals the requested value.

## Examples

- `productFib(714)` returns `[21, 34, true]`.
- `productFib(800)` returns `[34, 55, false]`.
