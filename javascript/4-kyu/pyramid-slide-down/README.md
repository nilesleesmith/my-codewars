# Pyramid Slide Down

**Rank:** 4 kyu  
**Language:** JavaScript

## Instructions

Given a triangle-shaped array of numbers, find the largest sum along a path starting at the top and moving at each step to either adjacent entry in the next row. The challenge includes very tall pyramids, so enumerating every path is impractical.

## Examples

- For `[[3], [7, 4], [2, 4, 6], [8, 5, 9, 3]]`, the result is `23`.
