# Jaden Casing Strings

**Rank:** 7 kyu  
**Language:** JavaScript

## Instructions

Add a `toJadenCase` method to strings. It should capitalize the first letter of every word while preserving the rest of each word.

## Examples

- `"how can mirrors be real".toJadenCase()` returns `"How Can Mirrors Be Real"`.
