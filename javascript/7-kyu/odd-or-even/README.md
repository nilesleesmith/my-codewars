# Odd or Even?

**Rank:** 7 kyu  
**Language:** JavaScript

## Instructions

Sum the numbers in an array and return `"even"` when the sum is even or `"odd"` otherwise. An empty array has a sum of zero.

## Examples

- `oddOrEven([0, 1, 4])` returns `"odd"`.
