# Make acronym

**Rank:** 7 kyu  
**Language:** JavaScript

## Instructions

Given a string of words, form an acronym using the first letter of each word in uppercase. The exact constraints should be checked against the original challenge.

## Examples

- `toAcronym("Portable Network Graphics")` returns `"PNG"`.
