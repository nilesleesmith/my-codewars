# Highest and Lowest

**Rank:** 7 kyu  
**Language:** JavaScript

## Instructions

Given a space-separated string of numbers, return a string containing the highest number, a space, and the lowest number.

## Examples

- `"1 2 3 4 5"` becomes `"5 1"`.
