# Sum of Digits / Digital Root

**Rank:** 6 kyu  
**Language:** JavaScript

## Instructions

Given a non-negative integer, repeatedly sum its decimal digits until the result contains one digit, then return that digit.

## Examples

- `16` becomes `1 + 6 = 7`.
- `942` becomes `9 + 4 + 2 = 15`, then `1 + 5 = 6`.
