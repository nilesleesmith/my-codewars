# Beginner Series #4 Cockroach

**Rank:** 8 kyu  
**Language:** JavaScript

## Instructions

Convert a cockroach’s speed from kilometers per hour to centimeters per second. Round down to the nearest integer.

## Examples

- `cockroachSpeed(1.08)` returns `30`.
