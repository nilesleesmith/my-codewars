# L1: Set Alarm

**Rank:** 8 kyu  
**Language:** JavaScript

## Instructions

Return whether an alarm should ring based on employment and vacation status. It rings only when the person is employed and not on vacation.

## Examples

- `setAlarm(true, false)` returns `true`.
