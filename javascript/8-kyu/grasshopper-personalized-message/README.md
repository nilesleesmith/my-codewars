# Grasshopper - Personalized Message

**Rank:** 8 kyu  
**Language:** JavaScript

## Instructions

Return `"Hello boss"` when the supplied name matches the owner, and `"Hello guest"` otherwise.

## Examples

- `greet("Daniel", "Daniel")` returns `"Hello boss"`.
