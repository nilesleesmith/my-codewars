# Removing Elements

**Rank:** 8 kyu  
**Language:** JavaScript

## Instructions

Return a new array containing every other element of the input array, starting with the first.

## Examples

- `removeEveryOther([1, 2, 3, 4])` returns `[1, 3]`.
