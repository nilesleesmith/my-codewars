# Find the first non-consecutive number

**Rank:** 8 kyu  
**Language:** JavaScript

## Instructions

Given an ordered array of integers, return the first value that is not exactly one greater than the preceding value. Return `null` if the sequence is consecutive.

## Examples

- `firstNonConsecutive([1, 2, 3, 5])` returns `5`.
