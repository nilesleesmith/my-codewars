# Grasshopper - Grade book

**Rank:** 8 kyu  
**Language:** JavaScript

## Instructions

Calculate the average of three scores and return a letter grade: A for at least 90, B for at least 80, C for at least 70, D for at least 60, and F otherwise.

## Examples

- `getGrade(95, 90, 93)` returns `"A"`.
