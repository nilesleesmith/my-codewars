# Sentence Smash

**Rank:** 8 kyu  
**Language:** JavaScript

## Instructions

Combine an array of words into a single sentence, with exactly one space between adjacent words and no leading or trailing separator. The input is an array of words of any length.

## Examples

- `["hello", "world"]` becomes `"hello world"`.
