# Sum Mixed Array

**Rank:** 8 kyu  
**Language:** JavaScript

## Instructions

Given an array containing integers and numbers represented as strings, return their numeric sum.

## Examples

- `sumMix([9, 3, "7", "3"])` returns `22`.
