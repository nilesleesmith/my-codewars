# Convert boolean values to strings 'Yes' or 'No'.

**Rank:** 8 kyu  
**Language:** JavaScript

## Instructions

Return `"Yes"` when the input boolean is `true` and `"No"` when it is `false`.

## Examples

- `true` returns `"Yes"`.
- `false` returns `"No"`.
