# Cat years, Dog years

**Rank:** 8 kyu  
**Language:** JavaScript

## Instructions

Given a whole number of human years, calculate the corresponding cat and dog years. The first year counts as 15 for both; the second adds 9 for both; each later year adds 4 cat years and 5 dog years.

## Examples

- `humanYearsCatYearsDogYears(1)` returns `[1, 15, 15]`.
- `humanYearsCatYearsDogYears(3)` returns `[3, 28, 29]`.
